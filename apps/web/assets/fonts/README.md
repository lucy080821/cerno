# Font cho ảnh biểu đồ trong email

`NotoSans-Regular.ttf`, `NotoSans-Bold.ttf`: Noto Sans (Google / Noto Project), giấy phép SIL Open Font License 1.1
(https://openfontlicense.org). Có đủ chữ tiếng Việt. Dùng cho `@resvg/resvg-js` khi đổi SVG biểu đồ thành PNG ở server
(máy chủ Linux thường không có font hệ thống đủ dấu). Nguồn: https://github.com/notofonts/notofonts.github.io (fonts/NotoSans/hinted/ttf).
